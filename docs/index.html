它能做什么

整页翻译，两种模式

替换模式直接换掉原文，双语模式用伪元素在原文下方追加译文——不插 DOM 节点，grid / flex 布局不会错位。

划词翻译

选中一段文字，浮窗里出译文，不用整页翻。

吸边悬浮球

拖到屏幕边缘自动吸附，点开是菜单：翻译 / 切模式 / 恢复原文 / 诊断 / 设置。

三套独立方案

每套方案各有自己的 Base URL、Key、模型、提示词和目标语言，能重命名、能整包导出导入。

快，而且省

流式输出边收边写，长短文本分组并发，超长段落自动拆句。译过的句子本地缓存，重开页面直接复用。

动态内容跟得上

无限滚动加载的新内容会自动补翻；支持 iframe 联动；随时「恢复原文」并掐断在途请求。

出问题查得到

一键诊断：这一页收到多少段、哪些被跳过、为什么被跳过——不用再靠猜。

实验性：图片翻译

点选页面图片，多模态模型识别文字并给框，canvas 采样背景色自动嵌字。

怎么装

  1. 去 Releases 下载 haloflow.crx 或 haloflow.user.js
  2. 扩展：打开 chrome://extensions（Edge 是 edge://extensions）→ 开启「开发者模式」→ 把 crx 拖进去
  3. 脚本：haloflow.user.js 拖进 Tampermonkey
  4. 打开设置，填 Base URL、API Key、模型，然后点「连接测试」
  5. 回到网页，点悬浮球 → 翻译本页

说明

不提供公共服务

需要你自己的 API Key。任何 OpenAI 兼容接口都行：DeepSeek、智谱 GLM、Kimi、OpenAI，或者自己搭中转。

Key 只存在本机

存在浏览器的本地存储里，不上传任何服务器。想集中管理可以部署仓库里的 relay/，把 key 留在服务端。
