译文

数字、代码和链接原样保留。

机翻腔

同一术语全文同一译法，长句按语义断开；数字、代码、URL 不译。

样式破坏

只改文本节点，不替换元素；双语用伪元素追加，grid / flex 不会错位。

它能做什么

整页翻译 · 两种模式

替换模式直接换掉原文；双语模式用 ::after 在原文下方追加译文，不插 DOM 节点。

划词翻译 · 高考模式

选中文字出译文；切到「高考」给出词性、词组、派生和例句，像翻词典一样。

吸边悬浮球

拖到边缘自动吸附，点开是菜单：翻译 / 切模式 / 恢复原文 / 诊断 / 设置。

三套独立方案

各有自己的 Base URL、Key、模型、提示词和目标语言，能重命名、整包导出导入。

快，而且省

流式输出、长短并发、超长段落拆句；译过的句子本地缓存（1200 条），重开页面直接复用。

动态内容跟得上

MutationObserver 跟随滚动加载的新内容；支持 iframe 联动；随时恢复原文并掐断在途请求。

出问题查得到

一键诊断：这一页收到多少段、哪些被跳过、为什么被跳过。

实验性 · 图片翻译

点选页面图片，多模态模型识别文字并给框，canvas 采样背景色自动嵌字。

怎么装

  1. 去 Releases 下载 haloflow.crx 或 haloflow.user.js
  2. 扩展：打开 chrome://extensions（Edge 是 edge://extensions）→ 开「开发者模式」→ 把 crx 拖进去
  3. 脚本：把 haloflow.user.js 拖进 Tampermonkey
  4. 打开设置，填 Base URL、API Key、模型，点「连接测试」
  5. 回到网页，点悬浮球 → 翻译本页
